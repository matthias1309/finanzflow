# Uberspace Deployment (Archiv)

Diese Dateien sind für das Deployment auf Uberspace relevant.  
**Hinweis:** Die App wird jetzt auf Raspberry Pi mit Docker deployed. Dieses Archiv bleibt für zukünftige Uberspace-Deployments.

## Dateien

- `deploy.sh` — Deployment-Skript für Uberspace
- `UBERSPACE_NOTES.md` (falls nötig) — spezifische Hinweise

## Verwendung

Falls du später wieder auf Uberspace deployen möchtest:

```bash
# Aus dem Archiv wiederherstellen
cp uberspace-archive/deploy.sh .

# Und der Anleitung in der originalen CLAUDE.md folgen
```
